# Culture Desk · 전국 주요 공연 검색

전국 230개 지역에서 원하는 시·군·구를 체크해 공연을 검색하는 프로그램입니다. 전시를 제외하고 불명확한 분류는 검토 대상으로 남깁니다. 공연 카드가 기본으로 나오며 표·지도로도 볼 수 있습니다. Windows 로컬 실행과 Vercel 웹 배포를 지원합니다.

웹 주소: **https://culture-desk.vercel.app** · 로그인이나 접속 암호 없이 바로 사용합니다.

처음에는 특정 지역을 체크하지 않고 **전국을 조회**합니다. **지역 선택 → 시·도 선택 → 시·군·구 체크 → 적용**으로 일부 지역만 좁혀 볼 수 있습니다. 아무 지역도 체크하지 않거나 전부 체크하면 전국을 조회합니다. 지역명 검색, 시·도 전체 선택, 전국 전체 선택과 모두 해제를 지원합니다. 이전 버전의 기본 7개 도시 선택은 복원하지 않습니다. 목록은 KOPIS 공식 검색 기준이며 일반구를 가진 일부 도시는 시 단위입니다. [지역 목록 근거](docs/research/national-regions.md)

지도는 **상단 ‘지도에서 보기’ 또는 메뉴 ‘지도 보기’**에서 바로 엽니다. [공연 지도 바로가기](https://culture-desk.vercel.app/#map). 지역·기간 조건은 카드·표·지도 사이에서 유지됩니다.

기본 기간은 **이번 달 1일~향후 3개월**입니다. 공연장의 **‘3D로 보기’**에서는 Cesium으로 해당 공연장을 살펴봅니다. 실제 건물 도형과 높이가 있으면 건물을 입체로 표시하고, 층수로 산정한 높이는 추정이라고 표시합니다. 도형·높이가 없는 경우에는 확인된 외곽 또는 위치만 표시합니다. Cesium과 건물 자료는 버튼을 눌렀을 때 불러오며 추가 API 키 없이 동작합니다.

## 실행

1. `Start Culture Desk.vbs`를 더블클릭합니다. 콘솔창 없이 로컬 서버를 시작하고 브라우저를 엽니다.
2. 주소는 기본 `http://127.0.0.1:4317`입니다.
3. 종료할 때 화면의 **프로그램 종료** 또는 `Stop Culture Desk.vbs`를 사용합니다. 브라우저 탭만 닫으면 서버는 계속 실행됩니다.

개발 환경은 Node.js 24.14 이상입니다. 다른 PC로 옮기거나 처음 설치하는 경우 프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
npm install
npm run build
npm start
```

개발 화면은 `npm run dev`로 실행합니다. 수집한 공연 자료는 서버의 SQLite에 저장됩니다.

## API 키 입력

현재 `.env`에 입력된 두 키로 실제 수집을 확인했습니다. 다른 환경에서는 `.env.example`을 `.env`로 복사해 입력합니다. 키를 채팅이나 공개 저장소에 보내지 마세요.

```dotenv
KOPIS_API_KEY=
CULTURE_API_KEY=
```

| 입력칸 | 발급받을 API |
| --- | --- |
| `KOPIS_API_KEY` | [KOPIS 공연예술통합전산망 OPEN API](https://kopis.or.kr/por/cs/openapi/openApiInfo.do?menuId=MNU_00074) |
| `CULTURE_API_KEY` | [한국문화정보원_한눈에보는문화정보조회서비스](https://www.data.go.kr/data/15138937/openapi.do) — 공공데이터포털의 일반 인증키(Decoding) |

입력 후 화면의 **데이터 연결 → 설정 다시 읽기**를 누르거나 프로그램을 다시 실행합니다. 도시·기간·출처를 선택해 수집을 시작하세요. 한쪽 키만 있어도 해당 출처를 수집할 수 있습니다. ‘키 입력됨’은 인증 성공이나 자료 수집 완료를 의미하지 않습니다. [신청 안내·활용 목적 입력 예시](docs/API_APPLICATIONS.md)

2026-10-16 전국 230개 지역·두 출처의 2026-10-01~2027-01-16 수집을 마쳤습니다. 전시 등을 제외한 공연 정보는 **5,600행(KOPIS 4,336 + 문화포털 1,264)**이며 전부 상세 정보와 공연장 좌표를 확보했습니다. 200개 지역에서 공연을 확인했고 나머지 30개 지역은 해당 기간·출처의 조회 결과가 0건입니다. 출처 간 중복 공연은 포함될 수 있습니다. [전국 수집 감사](docs/verification/national-final-audit.json)

## 사용과 자료 해석

- 공연 찾기: 전국 지역 복수 체크·기간·장르·검색어·공연 상태·관람료·연령으로 조회합니다.
- 공연 지도: 도시를 선택해 목록을 좁히고 공연장 위치와 공연 상세를 확인합니다. 원본 좌표가 없는 경우에는 도시 중심의 집계 표시로 구분합니다. 지도 API 키는 필요 없습니다.
- 공연장 3D: Cesium에 OpenStreetMap의 확인된 공연장 외곽을 표시합니다. 실제 외관 사진·정밀 건축 모델과는 다르며, 층수 기반 높이는 별도로 표시합니다.
- 상세 보기: 날짜·공연장·관람료 원문·출연진·주최 등 제공되는 항목과 원문을 확인합니다.
- 엑셀: 선택한 지역과 조회 조건에 맞는 공연 목록 및 조회 근거를 함께 내보냅니다.
- 데이터 연결: 지역과 기간을 선택해 자료를 수집하고 출처별 진행·오류·중단·재개를 관리합니다. 새로 선택한 지역의 자료가 아직 없다면 이 화면에서 수집을 시작하세요. 전국 목록 등록은 전국 공연 수집 완료를 의미하지 않습니다.

출처가 다른 동일 공연은 각각 표시됩니다. 등록 행 수를 고유 공연 수나 인기 순위로 해석하지 마세요. ‘등록 자료 0건’은 해당 도시 공연이 없다는 뜻이 아닙니다. 관람료는 관객 입장 가격이며 제작비·섭외비가 아닙니다. 상세 미수집 항목이 남아 있으면 관람료·연령 필터는 부분 결과로 표시합니다.

수집은 31일 구간·페이지 단위로 나눠 기록합니다. 인증 실패와 호출 한도는 수집을 보류하고, 일반 오류는 제한된 횟수만 재시도합니다. 앱을 다시 실행하면 미완료 작업을 이어갑니다. 정기 갱신은 서버가 실행 중일 때만 동작합니다.

## 저장·백업·복원

기본 데이터 파일은 `data/culture.db`입니다. `.env`, `data/`, `logs/`는 Git에서 제외됩니다.

로컬 화면의 백업 기능 또는 `npm run backup`으로 `data/backups/`에 SQLite 백업을 만듭니다. 복원할 때는 프로그램을 먼저 종료하세요.

```powershell
npm run restore -- data/backups/백업파일.db
```

복원은 DB 무결성과 스키마를 확인하며 기존 DB를 `.before-restore-시각.db`로 보존합니다. API 키가 든 `.env`는 데이터 백업에 포함되지 않습니다. 데이터 폴더를 복사할 때는 서버를 종료하거나 백업 기능을 사용하세요.

## 개발·검증

```powershell
npm run typecheck
npm test
npm run build
```

구현은 React/Vite/TypeScript + Fastify + SQLite 단일 워커 구조입니다. 서버는 `127.0.0.1`에만 연결됩니다. API 키는 서버 설정에서만 읽고 화면 응답·엑셀에 포함하지 않습니다. 상세 외부 HTML은 실행하지 않습니다.
