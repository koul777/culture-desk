# Culture Desk · 전국 주요 공연 검색 프로그램

2026-10-16 갱신 · 현재 배포와 완료된 전국 수집·자동 갱신을 반영한다. 초기 논의는 `MEETING_NOTES.md`, `IMPLEMENTATION_CONTRACT.md`에 이력으로 보존한다.

## 목적

전국에서 개최되는 주요 공연을 지역과 기간으로 검색하고, 공연장 위치와 실제 건물 자료를 함께 살펴본다. 전시는 제외한다. 로그인·접속 암호·기획 메모·보관함 없이 검색 화면을 바로 연다. 근거 없는 인기 순위나 임의의 행사·건물 정보는 제공하지 않는다.

## 사용 흐름

1. 처음에는 체크된 지역 없이 전국의 저장된 공연 자료를 조회한다. 기본 기간은 이번 달 1일부터 오늘로부터 3개월 뒤까지다.
2. 지역 선택에서 시도와 시군구를 체크한다. 미선택·전체 선택은 전국, 일부 체크는 해당 지역만 조회한다.
3. 공연 카드를 확인하고 기간·장르·검색어·상태·관람료·연령·출처로 좁힌다.
4. 같은 조건으로 카드·표·지도 보기를 전환한다. 지도는 상단 버튼·별도 메뉴 또는 `/#map` 주소로 바로 연다.
5. 실제 공연장 마커에서 공연 목록·상세 또는 **공연장 3D로 보기**를 연다. 건물 도형·높이 확보 상태에 따라 입체·평면 외곽·위치만 구분해 표시한다.
6. 상세에서 제공된 일정·가격·출연진·주최·원문을 확인하고 검색 결과를 엑셀로 받는다.
7. 다른 기간을 수집하거나 상세를 보충하려면 데이터 연결에서 지역·기간·출처를 정해 실행한다. 진행 상태와 부분 결과 안내를 함께 확인한다.

## 화면과 구현 상태

| 화면 | 구현 기능 |
| --- | --- |
| 공연 검색 | 전국 230개 지역 복수 체크, 지역명 검색, 전체 선택/해제, 검색 조건, 카드 기본 보기 |
| 표·2D 지도 | 같은 조건의 표와 실제 공연장 위치, 팝업 공연 목록·상세·3D 연결 |
| 공연장 3D | Cesium 지연 로딩, 실제 건물 도형 표시, 층수 추정·높이 미확인·도형 없음 안내, 닫은 뒤 기존 검색 유지 |
| 공연 상세 | 제공기관의 날짜·장소·가격·연령·공연 시간·출연진·주최·연락처·원문 |
| 데이터 연결 | 두 출처 연결 상태, 지역·기간·출처별 수집, 상세 보충, 진행·오류·중단·재개 |
| 엑셀 | 검색 결과와 출처·수집 범위·부분 결과 여부를 담은 조회 근거 |

현재 두 공연 API 키는 실제 호출로 검증됐으며 **신규 API 신청은 필요 없다**. Cesium 화면도 추가 지도 인증키 없이 동작한다.

## 전국 자료 수집

전국 카탈로그는 KOPIS 공식 검색 API 기준 **230개 지역·16개 시도 그룹**이다. 일부 일반구를 가진 도시는 시 단위로 제공한다. 기존 7개 도시 ID와 좌표는 유지한다.

2026-10-01~2027-01-16 범위의 **230개 지역 × 2개 출처, 총 460개 지역·출처 조합에서 목록·상세 단계가 완료**됐다. **5,600행·200개 지역이 2026-10-16 최종 집계**이며 전체 공연의 상세·좌표를 확보했다. 독립 예약 작업으로 매일 범위를 이동해 갱신하고 실패하면 체크포인트부터 재개한다. [자동 갱신 운영](AUTOMATIC_REFRESH.md) 초기 7개 도시 103행은 이전 검증 이력이다.

KOPIS와 문화포털의 원본 행을 유지하므로 서로 같은 공연이 포함될 수 있다. 합계를 고유 공연 수나 인기 순위로 표현하지 않는다. 전시는 제공기관 분류로 제외하고 불명확한 항목은 검토 대상으로 남긴다. 관람료는 관객 입장 가격이다.

제공기관이 반환한 좌표만 실제 공연장 위치로 사용한다. 좌표가 없으면 도시 중심을 공연장으로 대체하지 않으며 해당 공연은 목록에서 계속 조회된다. 지도 조회는 현재 목록 페이지와 별도로 조건에 맞는 항목을 가져오되 최대 10,000행·3 MiB 한도와 잘림 여부를 표시한다.

## 공연장 건물의 근거

현재 실제 OSM 도형을 확인해 보관한 공연장은 3곳이다.

- 원주 백운아트홀은 실제 도형과 OSM 2층 정보를 사용한다. 표시 높이 **6m는 층당 3m에 따른 추정**이며 실측값으로 표시하지 않는다.
- 안동문화예술의전당과 여수 예울마루는 실제 도형의 평면 외곽을 표시한다. 높이는 미확인이다.
- 다른 공연장은 허용된 Overpass 제공처에서 동적으로 확인한다. 도형이 없거나 조회가 실패하면 위치만 표시한다. 임의의 가까운 건물이나 높이를 생성하지 않는다.

건물 도형은 실제 공연장 좌표 포함 여부와 이름 증거로 연결한다. 다른 이름의 건물이거나 여러 건물 중 구분할 수 없으면 표시를 보류한다. 출처·확인 시각을 보존하고 확인된 원자료 캐시에는 유효기간을 둔다. 현재 구성은 도시 전체의 실사 3D 또는 정밀 지형 서비스가 아니다.

## 실행·저장·게시

React/Vite/TypeScript 화면, Leaflet 2D 지도, CesiumJS 공연장 화면, Fastify 서버를 사용한다. Cesium과 관련 정적 자산은 3D 화면을 열 때 불러온다. 로컬은 SQLite와 Windows 실행기를, Vercel은 정적 화면·Node.js API·Neon 스냅샷 저장을 사용한다.

클라우드 스냅샷은 gzip 무손실 압축으로 저장한다. 압축본 16 MiB·복원 SQLite 128 MiB 한도를 검사하며 기존 비압축본도 읽는다. 쓰기는 동일한 Postgres 행 잠금과 트랜잭션으로 보호하고 실패하면 이전 자료를 유지한다.

전국 일괄 수집은 별도 SQLite에서 진행하고 체크포인트를 감사한 뒤 운영 DB에 병합한다. 기존 공연 ID·최신 상세·개인 자료를 보존하고 반복 게시로 수집 이력을 중복시키지 않는다. 새 미완료 수집이 과거 완료 이력에 가려지지 않도록 완료 범위를 판단한다. 로컬 게시 시 실행 중 DB 잠금을 확인한다.

공개 웹은 검색·지도·공연장 도형·상세·엑셀·수집 API를 제공한다. 개인 메모와 관심 표시는 공개 응답과 내보내기에서 제외하며 원본 DB에서는 삭제하지 않는다. 키는 서버에만 보관한다. Cron 인증, 변경 요청의 JSON·동일 출처 검사, 저장 실패 롤백을 유지한다.

수집은 31일 구간·페이지·상세 작업 단위로 기록하고 제한적으로 재시도한다. 인증·호출 한도 오류는 보류한다. 완료된 작업은 보존되지만 Vercel의 제한된 실행이나 하루 한 번 Cron만으로 모든 대량 수집이 즉시 끝나는 것은 아니다. 운영 절차와 제한은 [Vercel 운영](VERCEL.md)을 따른다.

## 검증과 남은 확인

검색·지역 선택·지도·3D·상세·엑셀은 배포 후 실제 브라우저 검증을 수행했다. 원주 백운아트홀의 실제 도형과 추정 높이는 운영 사이트에서 확인했으며, 3D를 닫으면 검색과 2D 지도로 돌아간다. 데스크톱·모바일의 가로 넘침과 브라우저 오류를 검사했다.

남은 자료 검증은 다음과 같다.

- 진행 중인 전국 상세 수집의 완료·실패·미확인 상태 확인과 최종 집계 갱신
- 최종 체크포인트 감사 및 운영 반영 확인
- 좌표·건물 도형·높이가 없는 공연장의 상태를 숨기지 않고 안내
- 공개 건물 제공처가 정상인 경우에만 실제 도형 범위를 추가 확보

위 자료 검증이 끝나기 전에는 모든 상세정보·전국 모든 공연장 3D 확보가 완료됐다고 표시하지 않는다.
