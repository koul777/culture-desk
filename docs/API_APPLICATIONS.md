# 공연 검색 프로그램 API 연결·신청 안내

확인일: 2026-10-16

**현재는 신규 API 신청이 필요 없다.** 기존 `KOPIS_API_KEY`와 `CULTURE_API_KEY`를 실제 호출로 검증했고, 두 출처의 전국 목록 수집에 사용하고 있다. Cesium 공연장 보기와 2D 지도에도 추가 인증키가 필요하지 않다.

## 현재 연결된 서비스

| 서비스 | 서버 설정 이름 | 사용 목적 |
| --- | --- | --- |
| KOPIS 공연예술통합전산망 OPEN API | `KOPIS_API_KEY` | 공연 목록·상세·공연시설 주소·실제 좌표 |
| 한국문화정보원 한눈에보는문화정보조회서비스 | `CULTURE_API_KEY` | 지역 공연·문화행사 정보와 GPS 보완 |
| OpenStreetMap / Overpass | 추가 키 없음 | 지도 배경과 공연장에 대응하는 실제 건물 도형 조회 |
| CesiumJS | 현재 구성에 ion 키 불필요 | 선택한 공연장의 위치·건물 도형을 3D 화면으로 표시 |

전국 수집 범위는 2026-10-01~2027-01-16이다. 230개 지역 × 2개 출처의 목록·상세 단계가 모두 완료됐으며, **5,600행·200개 지역이 2026-10-16 최종 집계**다. 전체 공연의 상세와 실제 공연장 좌표를 확보했다. 초기 7개 도시 103행 수집은 이전 검증 이력이다.

## 새 설치 또는 키 재발급이 필요한 경우

현재 운영에 추가 신청하라는 뜻이 아니라, 키를 새로 발급하거나 별도 환경을 구성할 때 참고할 경로다.

| 서비스 | 공식 안내·신청 |
| --- | --- |
| KOPIS OPEN API | [공식 안내](https://kopis.or.kr/por/cs/openapi/openApiInfo.do?menuId=MNU_00074) · [인증키 신청](https://kopis.or.kr/por/cs/openapi/openApiUseSend.do?menuId=MNU_00074) |
| 한국문화정보원 한눈에보는문화정보조회서비스 | [공공데이터포털 활용신청](https://www.data.go.kr/data/15138937/openapi.do) |

두 기관의 키는 서로 다르다. 별도 전시정보·문양 API는 필요하지 않다. 제공기관의 승인 방식·호출 한도 등 신청 조건은 신청 시 공식 페이지에서 확인한다.

활용 목적 입력 예시:

> 전국 시·도와 시·군·구를 선택하여 주요 공연 정보를 조회·검색하는 프로그램 개발. 공연명, 일정, 장소, 장르, 관람료와 출처를 목록 및 지도에 표시하며 전시는 검색 대상에서 제외합니다.

문화포털은 신청 페이지의 Swagger 명세와 기본 주소 `https://apis.data.go.kr/B553457/cultureinfo`를 사용한다. 공연과 전시가 같은 서비스 구분에 포함되므로 제공기관 장르로 전시를 추가 제외한다. 사용하는 엔드포인트·파라미터는 [확인한 명세](research/culture-api-contract.json)에 기록했다.

KOPIS는 [개발가이드](https://kopis.or.kr/upload/openApi/공연예술통합전산망OpenAPI개발가이드.pdf)의 공연 목록·상세·시설 조회를 사용한다. 전국 지역 목록은 [확인한 지역 코드](research/national-regions.md)를 따른다. 여수·순천은 KOPIS 시도 12와 구군 1213·1215, 문화포털 시도 광주로 실제 응답을 확인했으므로 과거 코드 46을 다시 넣지 않는다.

## 인증키 입력과 보관

로컬은 프로젝트 루트 `.env`의 `KOPIS_API_KEY=`, `CULTURE_API_KEY=` 뒤에 각각 입력한다. 문화포털 키는 일반 인증키(Decoding)를 권장한다. 키를 변경했다면 파일을 저장하고 **데이터 연결 → 설정 다시 읽기**를 실행한다. 한쪽 키만 있어도 그 출처를 사용할 수 있으나 현재 환경은 두 키가 모두 연결돼 있다.

Vercel은 해당 프로젝트의 서버 환경 변수에 같은 이름으로 등록한다. 로컬 `.env` 수정만으로 운영 환경 변수가 변경되지는 않는다. 배포·재적용 절차는 [Vercel 운영](VERCEL.md)을 따른다.

키를 채팅·스크린샷·공개 저장소에 붙여넣지 않는다. `.env`와 `.env.vercel`은 배포 파일에 포함하지 않으며, 브라우저 코드와 API 응답에도 키를 전달하지 않는다. `DATABASE_URL`은 저장소 연결 설정이고 `CRON_SECRET`은 서버 예약 작업 인증값으로, 공연 검색 이용자가 별도로 신청할 API 키가 아니다.

## 지도·3D 범위와 추가 키

현재는 Cesium ion·VWorld·Kakao·Naver API 키를 신청할 필요가 없다. CesiumJS, OSM 배경, 타원체 지면과 공개 건물 도형을 조합한다. 전국의 모든 건물이 입체로 확보되는 서비스는 아니다.

- 원주 백운아트홀: 실제 OSM 도형과 2층 정보를 확인했다. **6m는 층당 3m를 적용한 추정값**으로 표시한다.
- 안동문화예술의전당·여수 예울마루: 실제 도형은 있으나 높이는 미확인이다. 화면에서는 초기 12m의 **높이 가정 모형·실측 아님**으로 표시하고, 슬라이더로 가정 높이를 바꾸거나 위에서 외곽을 볼 수 있다. 원본 API의 높이는 미확인(`null`)으로 유지한다.
- 다른 공연장: 허용된 Overpass 제공처에 동적으로 조회한다. 실제 도형은 있지만 높이가 없으면 같은 가정 모형을 사용한다. 일치하는 도형이 없거나 제공처가 응답하지 않으면 실제 공연장 위치만 표시한다.

확인된 3곳의 원자료에는 출처와 조회 시각을 기록해 캐시한다. 공공 조회 서버의 장애·사용량 제한 때문에 추가 건물 조회가 항상 성공하는 것은 아니다. 현재 기능에 필요한 신규 신청은 없으며, 향후 별도 지형·실사 건물 서비스로 확장할 때의 계약이나 키는 이번 구현 범위에 포함하지 않는다.
