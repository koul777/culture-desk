# Culture Desk 구현·검증 결과

2026-10-16 검증 기록 · [운영 사이트](https://culture-desk.vercel.app) · [지도 바로가기](https://culture-desk.vercel.app/#map)

이 문서는 당시의 배포·자료 검증을 보존한다. 이후 공개 웹은 GitHub Actions 수집 → 공개 JSON 스냅샷 → Vercel 배포로 전환했다. 현재 운영 구조와 검증 명령은 [프로그램 계획](PROGRAM_PLAN.md), [자동 갱신 운영](AUTOMATIC_REFRESH.md), [README](../README.md)를 기준으로 한다. 아래 DB·수집 API·인증키 연결 상태는 현재 운영의 재검증 결과가 아니다.

현재 제품은 **전국 주요 공연 검색 프로그램**이다. 로그인·접속 암호 없이 지역 체크와 기간 조건으로 공연을 찾고, 카드·표·지도·공연장 3D·상세·엑셀을 이용한다. 전시는 제외한다. 기획 메모·관심 보관함은 공개 화면에서 제거했으며 기존 개인 자료는 DB에 보존한다.

## 현재 배포와 수집 상태

- 전국 카탈로그는 공식 KOPIS 기준 **230개 지역·16개 시도 그룹**이다. 일부 일반구가 있는 도시는 제공기관의 시 단위로 묶인다.
- 전국 일괄 수집 범위는 **2026-10-01~2027-01-16**이다. 230개 지역 × KOPIS·문화포털 2개 출처, 총 **460개 지역·출처 범위의 목록·상세 단계가 모두 완료**됐다.
- **5,600행·200개 지역이 2026-10-16 최종 집계**다. KOPIS 4,336행·문화포털 1,264행이며 출처별 원본 행을 합산하므로 고유 공연 수와 다를 수 있다. 나머지 30개 지역은 지정 기간·두 출처의 실제 조회 결과가 0건이다.
- **전체 공연 5,600행의 상세 수집·공연장 좌표 확보가 완료**됐다. 목록 1,848페이지·상세 5,646건을 처리했고 실패 0건, 검토 46건·전시 등 제외 351건은 검색에서 분리했다.
- 기본 조회 기간은 **이번 달 1일~오늘로부터 3개월 뒤**다. 확인일 기준 2026-10-01~2027-01-16이며 사용자가 변경할 수 있다.
- 미선택·전체 선택은 전국, 일부 체크는 해당 지역만 조회한다. 전국 조회 결과가 특정 기간 밖의 모든 공연이나 실시간으로 등록되는 모든 공연의 수집 완료를 뜻하지는 않는다.

전국 목록·경량 지도 응답·Cesium 공연장 보기를 운영 사이트에 배포했다. 수집 체크포인트는 운영 DB에 출처 ID 기준으로 병합하며, 상세 수집이 진행되는 동안 마지막으로 게시된 체크포인트와 수집기 진행 시각이 다를 수 있다. 최종 독립 감사에서 allComplete=true, DB 무결성 정상, issues=[]를 확인했다. [최종 감사](verification/national-final-audit.json) · [운영·로컬 일치 검증](verification/national-final-live.json)

## 지도와 실제 건물의 표시 범위

2D 지도는 KOPIS 시설 좌표 또는 문화포털 GPS처럼 제공기관이 반환한 실제 공연장 좌표를 사용한다. 도시 중심은 공연장 위치로 표시하지 않는다. 좌표 없는 공연도 목록과 상세에서 조회할 수 있다.

공연장 마커의 **공연장 3D로 보기**로 Cesium 화면을 연다. 추가 Cesium ion·VWorld·Kakao·Naver API 키는 필요 없다. 현재 구성은 OSM 배경과 타원체 지면을 사용하며, 주변 도시 전체를 실사 3D로 재현하는 기능은 아니다.

실제 원자료를 확인해 보관한 건물은 다음 3곳이다.

| 공연장 | 실제 도형 근거 | 현재 높이 표시 |
| --- | --- | --- |
| 원주 백운아트홀 | [OSM 건물 부분 도형 581720573](https://www.openstreetmap.org/way/581720573), [이름이 일치하는 공연장 지점](https://www.openstreetmap.org/node/4633865071) | 등록된 2층 × 3m = **6m 추정 높이**. 실측 높이로 표시하지 않음 |
| 안동문화예술의전당 | [OSM 도형 549155025](https://www.openstreetmap.org/way/549155025) | 높이 미확인. 초기 12m의 **높이 가정 모형·실측 아님** 표시 |
| 여수 GS칼텍스 예울마루 | [OSM 도형 187778995](https://www.openstreetmap.org/way/187778995) | 높이 미확인. 초기 12m의 **높이 가정 모형·실측 아님** 표시 |

높이 가정 모형은 확인된 실제 외곽에 화면상의 높이를 적용한 것이다. 슬라이더로 가정 높이를 바꾸거나 위에서 외곽을 볼 수 있으며, 실제 3D 원본이나 실측 높이를 확보했다는 의미가 아니다. 원본 API의 미확인 높이는 `null`로 유지한다.

원자료 캐시에는 출처·좌표·조회 시각을 기록하며 검증일로부터 30일 동안 사용한다. 다른 공연장은 허용된 Overpass 제공처에 동적으로 조회한다. 실제 도형은 있지만 높이가 없으면 가정 모형으로 구분하고, 도형을 찾지 못하거나 제공처가 실패하면 공연장 위치만 표시한다. 좌표와 도형 이름이 충돌하거나 여러 도형 중 특정할 수 없으면 건물 표시를 보류한다.

주요 시설 17곳을 대상으로 추가 확보 가능성을 검토했으나, 단건 조회부터 제공처가 HTTP 500/504를 반환해 대량 요청을 진행하지 않았다. 현재 전국 공연장 모두에 3D 건물이 확보된 상태는 아니다.

## 저장·게시와 개인정보 보존

로컬은 `data/culture.db`의 SQLite를 사용한다. Vercel은 Node.js API와 Neon Postgres에 보관한 SQLite 스냅샷을 사용한다. 새 스냅샷은 gzip으로 무손실 압축하며 기존 비압축 SQLite도 읽는다. **압축 저장 한도는 16 MiB, 복원 DB 한도는 128 MiB**다. 한도를 넘는 쓰기는 기존 데이터를 보존하고 거절한다.

전국 체크포인트 게시 전 운영 DB를 백업한다. 병합은 기존 공연 ID·개인 자료를 유지하고, 더 오래된 자료나 실패한 상세가 최신 완성 상세를 덮지 않도록 검사한다. 완료 범위는 후속 미완료 수집과 충돌하지 않게 처리하며 로컬 게시도 실행 잠금을 따른다. 압축을 지원하는 코드 배포와 운영 읽기 확인 후 압축 스냅샷을 게시한다.

공개 JSON·지도·엑셀에는 기존 개인 메모나 관심 표시를 노출하지 않는다. API 키는 서버 환경에서만 사용하며 브라우저 배포 파일에 포함하지 않는다. 클라우드 변경 요청의 동일 출처·JSON 검사와 Cron 인증, 저장 실패 롤백을 유지한다. 자세한 운영 절차는 [Vercel 운영](VERCEL.md)에 있다.

## 현재 검증 근거와 남은 확인

- 수집·조회 성능 개선 후 전체 테스트 **189/189**와 빌드를 통과했다. 운영 복사본의 동일 상세 40건은 38.98 → 11.52초, 스냅샷 저장은 40 → 12회였고 전체 6,011개 레코드의 데이터·원본 해시가 일치했다. 실제 API 속도 보장 수치는 아니다. [성능 비교·보존 검증](COLLECTION_PERFORMANCE.md)
- README 홍보 영상과 3D 모형 조작 개선 후 자동 테스트 **154/154**와 빌드를 통과했다. 실제 건물·가정 높이 구분, 원본 높이 보존, 375/390px 모바일, 키보드 조작과 시간초과를 확인했다. [개선 테스트](verification/promo-3d-tests.txt) · [개선 빌드](verification/promo-3d-build.txt) · [3D 화면 검증](verification/venue-3d-refined-report.json)
- 운영 배포에서도 원주 층수 기반 모형과 안동 높이 가정 모형을 확인했다. [운영 3D 검증](verification/promo/production-3d-check.json)
- 홍보 영상은 README 전용으로 `docs/media`에 보관한다. 프로그램의 영상 페이지·정적 영상 파일·전용 경로는 제거했으며 Vercel 배포에 포함하지 않는다. 기존 영상 재생 검증 파일은 제거 전 이력이다.
- 2026-10-16 기존 배포 검증에서 전국 수집·Cesium·지도 클러스터·자동 갱신·기록 보존을 포함한 **150/150 테스트가 통과**했고 TypeScript 검사와 Vite 빌드도 성공했다. 높이 가정 모형 UI를 추가하기 전의 검증 기록이다. [테스트 로그](verification/final-release-tests.txt) · [빌드 로그](verification/final-release-build.txt)
- 운영 사이트에서 모의 요청 없이 원주 백운아트홀의 실제 도형과 층수 기반 추정 높이를 확인했다. 1440px 데스크톱·390px 모바일에서 Cesium을 열고 닫아 검색과 2D 지도로 복귀했으며, 모바일 가로 넘침·브라우저 오류는 없었다. [운영 검증 기록](verification/cesium-vercel-report.json) · [데스크톱](verification/cesium-vercel-desktop.png) · [모바일](verification/cesium-vercel-mobile.png)
- 건물 API 검증은 실제 도형 연결, 충돌·모호한 연결 거부, 중정 보존, 높이 단위·층수 추정, 캐시·요청 병합·제공처 실패 처리와 확인된 원자료 캐시를 포함한다.
- 전국 최종 수집·상세·좌표가 완료됐다. 자동 갱신은 독립 예약 실행과 체크포인트 복구를 사용한다. [자동 갱신 운영](AUTOMATIC_REFRESH.md)

## 초기 구현·검증 이력

아래 숫자는 전국 수집 이전의 7개 도시 검증 기록이며 현재 전국 자료 규모가 아니다.

- 2026년 10월 안동·여수·순천·강릉·원주·충주·공주에서 KOPIS 78행 + 문화포털 25행 = **103행**을 수집하고 당시 상세 수집을 마쳤다. 101행에 실제 공연장 좌표가 있었고 위치 미확인 2행이 남았다.
- 초기 화면 검수에서는 전국 미선택·전체 선택·전체 해제 모두 저장된 103행을 반환했고, 여수+원주는 28행이었다. 당시 실제 공연장 마커는 34개였다. [이전 UI 검증](verification/ux-vercel-checks.json) · [이전 지역 선택 검증](verification/vercel-national-checks.json)
- 로그인·관심 공연·메모가 있던 초기 버전의 검증 기록은 이력으로 보존한다. 현재 제품에서 해당 UI와 공개 API를 제공한다는 의미가 아니다. [초기 클라우드 검증](verification/cloud-integration.json) · [검색 전용 전환 검증](verification/search-only-vercel-checks.json)
- 초기 지역 선택·UI 개선 단계의 테스트는 106/106이었다. 현재 검증 숫자와 혼용하지 않는다. [당시 로그](verification/ux-refinement-tests.txt)

초기 협업에서는 Codex가 작업을 배정·통합하고 Claude Code가 화면·접근성을, Cursor Agent가 제공기관 어댑터를, 별도 Codex 검증 담당이 서버·수집·내보내기를 맡았다. 이후 전국 지역·지도·클라우드·Cesium 개선은 분담 검토와 통합 검증을 거쳤다. 초기 작업 식별자와 산출물은 `docs/orchestration/` 및 `docs/reviews/`에 보존한다.
