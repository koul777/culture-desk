# 첫 엑셀 응답 비교

2026-10-19 KST · 원본 5,649행 · 초기 보존본과 `candidate-wave11-selection` 비교.

새 Node 프로세스를 매번 실행한 50쌍에서 완전한 엑셀 응답을 받은 시점의 중앙값은 **2,077.08 → 1,853.48ms**, p95는 **2,735.79 → 2,590.00ms**였다. 중앙값 감소는 10.8%이며, 50쌍 중 38쌍에서 후보가 빨랐다. 같은 쌍끼리 계산한 차이의 중앙값은 −214.71ms다. 두 집단의 중앙값 차이와 쌍별 차이의 중앙값은 서로 다른 통계다.

| 단계 | 기존 중앙값 | 후보 중앙값 |
| --- | ---: | ---: |
| 프로세스 시작부터 응답 본문 수신 완료 | 2,077.08ms | 1,853.48ms |
| 처리기 import | 770.51ms | 243.60ms |
| import 이후 첫 요청 처리 | 1,222.43ms | 1,516.81ms |

ExcelJS 지연 로딩은 import 비용 일부를 첫 요청으로 옮긴다. 따라서 import 시간만으로 엑셀 개선을 주장하지 않는다. 위 총 응답 시점에는 이동한 작업도 포함되며, 엑셀 검증·프로세스 종료는 제외한다. 각 단계의 중앙값을 더해 총 중앙값을 재구성할 수는 없다.

순서에 따른 세 구간의 응답 중앙값은 각각 2,027.05→1,936.38ms, 2,202.77→1,989.27ms, 2,078.94→1,836.61ms였다. 모든 구간에서 같은 방향이었지만, 구간당 16–17쌍으로 별도의 꼬리 지연 결론을 내리지 않는다.

AB/BA 순서를 사용하고 변형별 준비 실행 2회를 별도로 보존했다. 측정 중 다른 팀의 빌드·테스트·브라우저 작업을 중단했으며, 사용자의 다른 프로그램은 제어하지 않았다. 직전 30초 호스트 관측은 평균 CPU 46.68%, 최대 62.50%, 최소 여유 메모리 약 3,111MiB였다. OS 파일 캐시는 비우지 않았으며 외부 네트워크 성능이나 실제 배포 환경의 지연을 측정한 결과는 아니다.

모든 워크북의 검증 대상 내용은 동일했다. 행·셀 값·스타일·조회 근거·워크시트 구조를 비교하며, 검증된 추출 시각만 정규화한 의미 해시는 `9c44d99427dbe48c18a7087cfab23597006421a482e0cd1ca524f2890fef2154`다. 원본 스냅샷 SHA-256은 `09577634afcd8ebdd244053a92d68e1ff944abe9bcebe8cf5ab364e68d86e473`로 유지됐다. 실행 전후 제품 소스와 별도로 기록한 하네스 7파일·양쪽 스냅샷도 변경되지 않았다.

## 지역 51행 별도 비교

`cities=yeosu,wonju`를 지정한 별도 50쌍에서도 워크북 51행과 조회 근거의 의미 해시는 모두 같았다. 본문 수신 완료 중앙값은 **5,225.95 → 4,792.59ms**(8.3% 감소), p95는 **8,347.95 → 7,414.04ms**(11.2% 감소)였다. 50쌍 중 39쌍에서 후보가 빨랐고, 쌍별 차이의 중앙값은 −322.36ms였다.

| 단계 | 기존 중앙값 | 후보 중앙값 |
| --- | ---: | ---: |
| 프로세스 시작부터 응답 본문 수신 완료 | 5,225.95ms | 4,792.59ms |
| 처리기 import | 2,932.23ms | 871.19ms |
| import 이후 첫 요청 처리 | 2,013.04ms | 3,621.66ms |

이 실행에서도 지연 로딩은 첫 요청으로 비용을 이동시켰다. 총 응답 시간에 그 비용을 포함했으며 작은 엑셀의 속도가 나빠진다는 결과는 관측되지 않았다. 세 구간의 응답 중앙값은 6,089.61→5,389.39ms, 4,874.96→4,556.74ms, 5,168.70→4,897.38ms였다. 구간 간 절대 시간 차이가 크므로 한 환경의 고정 응답 시간으로 해석하지 않는다.

지역 실행 직후 관측은 평균 CPU 61.91%, 최대 66.96%, 최소 여유 메모리 약 1,321MiB였다. 직전 공통 관측에서도 최소 여유 메모리가 약 1,292MiB였다. 전국 비교와 호스트 상태·실행 시각이 다르므로 **51행이 5,649행보다 느리다는 비교에는 사용할 수 없다**. 두 실험의 절대 시간을 서로 비교하거나 실제 배포의 체감 시간으로 일반화하지 않는다. 의미 해시는 `19a7eaa407b25616c75e087b3562e15e383b00bf76a1f54f52c23237051db832`이며, 소스·하네스 7파일·양쪽 스냅샷은 실행 전후 동일했다.
