# 브이월드 연결과 검색 장애 복구 검증

2026-10-16 한국 시간 기준. 운영 주소는 https://culture-desk.vercel.app 입니다.

## 반영한 기능

- `.env`의 `VWORLD_API_KEY`를 운영 Vercel Production 환경에 등록했습니다. 실제 키 값은 Git과 정적 빌드에 포함하지 않았습니다.
- 공연장 3D를 열 때만 공식 WebGL 3.0 SDK를 별도 프레임에서 불러옵니다. 통합 LoD 건물 레이어를 우선 사용하고, 미지원이면 기존 레이어로 전환합니다.
- 지형 높이를 반영하고, SDK의 초기 이동 애니메이션이 공연장 시점을 덮어쓰는 현상을 수정했습니다. 닫힌 창이나 늦은 응답은 카메라를 다시 움직이지 않습니다.
- 연결 실패 시 재시도와 기존 Cesium 건물 외곽 모형을 제공합니다. 기존 모형도 배경 이미지 로딩을 기다리지 않고 먼저 표시합니다.

## 실제 지도에서 확인한 범위

원주백운아트홀과 안동문화예술의전당의 실제 좌표에서 인증과 지도 연결을 확인했습니다. 수정 뒤 공연장 시점이 20초 관찰 동안 유지되고 배경 자료가 선명하게 표시됐습니다. 원주·안동 검증은 실제 SDK와 실제 제공기관 요청으로 수행했으며 목업 건물 이미지를 사용하지 않았습니다.

**지도 준비 완료는 공연장 건물의 입체 모델 제공을 보장하지 않습니다.** 안동에서 통합 건물 레이어 존재와 표시 호출은 확인했지만, 추가 건물 형상과 해당 공연장 입체 모델은 확정하지 못했습니다. 따라서 전국 모든 건물이 3D로 제공된다고 안내하지 않습니다. 사용자는 기존 외곽 모형으로 전환할 수 있습니다.

## 검색 장애와 복구 상태

Neon이 `53000` 사용량 한도 초과로 DB 연결을 거절하여 공연 조회가 실패했습니다. 홈페이지 자체는 정상 응답했습니다. 한도의 종류는 확인되지 않았으며 요금제 변경은 하지 않았습니다.

검증한 백업의 공개 공연 **5,615건**을 서버 전용 복구 자료로 포함했습니다. 기준 시각은 **2026-10-16 20:19:02 한국 시간**입니다. 메모·관심 표시·원본 API 응답·수집 큐·인증정보는 제외했습니다. 원본 DB를 덮어쓰지 않았습니다.

현재 검색·지역 체크·지도·상세·엑셀은 임시 자료로 이용할 수 있습니다. 수집과 자동 갱신은 중단 상태로 표시하며, DB 연결이 정상화되면 운영 데이터 조회로 자동 복귀합니다. **이 복구가 Neon 제한 해소나 최신 자료 갱신 완료를 의미하지는 않습니다.**
